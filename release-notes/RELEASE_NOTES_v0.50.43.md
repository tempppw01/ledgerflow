## 修:「添加了个股,但是无法看到净值」

### 根因(用前后对照钉死的)

取个股行情的接口把 secid 过滤成 **`/^[01]\.\d{6}$/`** —— 那是 **A 股**的形状。
美股 `105.AAPL`、港股 `116.00700` 全被拒,服务端直接返回 **500**:

```
请求 105.AAPL → HTTP 500 "Stock secids must contain one or more valid security identifiers."
请求 0.000001 → HTTP 200(所以 A 股一直是好的)
```

于是**美股/港股个股永远取不到价** —— 而界面那一格写的是「净值」,净值只有基金才有,
个股自然停在「待更新」;「持有份额 × 单价」的市值也算不出来(整条快照直接返回 null)。

前端那一侧**同样**有一份 `[01].六位数字` 的过滤,所以即使后端放开也传不过去 —— 两边都要改。

### 改了什么

| 位置 | 改动 |
| --- | --- |
| 服务端 secid 过滤 | 放宽为「市场.代码」(`^\d+\.[A-Za-z0-9]+$`),A股/美股/港股都放行;乱码仍然拒绝 |
| 服务端行情字段 | 补 `f2`(最新价)—— 原来只取涨跌幅,根本没法算市值 |
| 前端 secid 过滤 | 与服务端同样放宽 |
| 前端行情类型 | 带上 `price` |
| 自选模型 | 新增 `secId` 与 `lastPrice`;加入个股时把 `secId` **存成字段**(以前只拼进 note,取不到价) |
| 刷新逻辑 | 个股走行情接口(**原来一律走基金快照,所以个股刷新必然失败**) |
| 市值计算 | 单价取「基金净值」**或**「个股最新价」—— 原来只认净值 |
| 行内显示 | 个股显示「**现价**」而不是「净值 / 待更新」 |
| 加入个股时 | 顺手取一次最新价,不用等手动刷新 |

对**已经加过**的个股也做了兼容:老数据里 `secId` 只被拼进 note(形如 `… · 105.AAPL`),
现在会从 note 里兜出来,不用重新添加也能取到行情。

### 验证

- **前后对照**(最有说服力的那条):旧过滤下 `105.AAPL` → 500,新过滤下 → 200 且带
  `price: 349.08`;A 股两边都是 200(说明只影响 A 股以外的标的)
- 实际取到:苹果 **349.08**、英伟达 **165.05**、腾讯控股 **341.6**、平安银行 **12.3**
- 新增 2 条守卫测试(A股/美股/港股都放行 + 乱码仍拒绝 + 非法输入不请求上游);
  **证伪**:把过滤改回旧版 → 第一条立刻失败
- 前端 1190 项 / 159 文件、服务端全过、九道闸门 + 演示库基线全 0
