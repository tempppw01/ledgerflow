## 记一笔:「再记一笔」

借鉴了同类记账 App 记一笔界面的一个做法 —— **连着记多笔时不用反复重开弹层**。

### 现在的行为

快速记账弹层底部多了「**再记一笔**」(主操作仍是「完成记账」):

- 点「再记一笔」:这一笔**存下**,弹层**保持打开**,类型 / 分类 / 账户 / 日期**都留着**,
  只清空金额与备注 —— 备注属于单笔,留着会误记到下一笔;
- 点「完成记账」:照旧存下并关闭。

### 为什么只做这一条

参考界面里还有几处(大字号金额、分类面包屑、时间行带 ✕ 清除、拍照、存为模板)——
但只有「再记一笔」是**日常高频且现在确实缺**的,其余要么我们已有等价物,要么属于更大的改造。
一次做一条、做扎实。

### 验证(浏览器 + 数据库双证据)

临时账号实测,连记两笔:

| 步骤 | 结果 |
| --- | --- |
| 输入 12.5 → 点「再记一笔」 | 金额框**清空** ✓,弹层**保持打开** ✓ |
| 接着输入 7.3 → 再点「再记一笔」 | 又存一笔 ✓,当日合计从 ¥12.50 变成 **¥19.80** ✓ |
| 查服务端库 | **两笔都在**:¥12.5 与 ¥7.3 ✓ |

另一个顺带验到的正确行为:金额为空时点「完成记账」会被校验拦住、弹层不关 —— 这是对的。
