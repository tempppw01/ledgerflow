## 选「预算」时,表单会说明它到底算什么

上一版把「预算」型的语义定了案(钱划出账户,但不算花掉)。但界面上原来只有「预算」两个字,
**没有任何解释** —— 用户不可能知道它到底算不算支出。这一版把这个已定的语义直接写在表单里。

### 现在会看到什么

在「新增/编辑交易」里把类型选成「预算」,下拉框下方会出现一行说明:

> 预算型:把钱划出账户作预留,账户余额会减少,但不计入支出统计。

换成别的类型,说明消失。

### 为什么加这一行

上一版做那个口径决定时,我查到全项目对「预算」型的处理是 **5 处不计入、1 处计入**,
据此把那一处对齐 —— 但整个中文语言文件里,「预算」只作为**类型名**和**智能预算功能名**出现,
**没有一句定义**。也就是说用户只能靠猜。决定既然做了,就该让人看得见。

### 验证

浏览器实测(临时用户,不碰演示库):

| 状态 | 说明是否出现 |
| --- | --- |
| 选「支出」 | 不出现 |
| 选「**预算**」 | **出现** |
| 换回「支出」 | 不出现 |

实现上用 `tf(key, 兜底文案)`,所以即使语言文件缺键也不会露出原始 key;中英各加一条,
`i18n:check` 与 `check:dynamic-i18n` 都通过。
