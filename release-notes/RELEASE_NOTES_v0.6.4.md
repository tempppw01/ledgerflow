# LedgerFlow v0.6.4

发布日期：2026-08-08

LedgerFlow v0.6.4 聚焦投资理财页的数据可靠性与定投回测能力，完善 A 股、美股、日股和韩股指数的历史走势与模拟入口。

## 大盘历史与定投模拟

- 新增美股（道琼斯、标普 500、纳斯达克、纳斯达克 100）、日经 225、韩国综合的 Yahoo Finance 日线历史数据。
- 历史走势区域可直接选择 A 股或国际指数，并使用同一套区间和定投模拟工具。
- 定投支持每个交易日、指定每周几、指定每月几号；计划日遇非交易日时顺延至下一个可用交易日。
- 模拟结果展示实际买入区间和估值日，并明确收益率为模拟盈亏除以累计投入（未年化）。
- 修复每期金额为 1000 时被浏览器步长校验拦截的问题。

## 稳定性与界面精简

- 修复活动数据与回收站中存在相同 ID 时的关系型数据库唯一约束错误。
- 移除重复的“投资风向”页面与入口；旧地址会自动返回投资主页。
- 国际行情与历史数据均通过服务端同源代理访问，减少浏览器跨域和 Token 配置造成的干扰。

## 验证

- `npx tsc --noEmit`、相关 ESLint 检查、`npm run build` 通过。
- 投资 API、定投模拟和投资页测试通过；市场服务端测试通过。
- 已在 Codex 内置浏览器验证道琼斯历史曲线和每个交易日定投模拟。
- 全量 Vitest 当前仍有既有的非投资模块失败（251 通过、6 失败），本次相关测试均通过。
