## 两个「结清」做的事不一样,其中一个还是无确认的一键清零

这一版 1 个提交。继续在还款管理里找「动钱」的问题。

### 症状

还款管理里有**两个**「结清」入口,口径不同:

| 入口 | status | 剩余本金 |
| --- | --- | --- |
| 卡片右键菜单 | settled | **清零** |
| 详情面板按钮 | settled | **一动不动** |

所以从详情面板结清之后,同一个负债自己跟自己矛盾 —— 卡片上写着「已结清」,
下面却还挂着:

- 剩余本金 **¥12,860.40**
- 最低还款 ¥1,286.04
- 一整张「未来 12 期」还款表、合计 ¥15,432.48

而右键菜单那条虽然口径是对的(结清就该没有剩余本金),却**没有任何确认**:
点一下就把 ¥12,860.40 清零,界面上也没有撤回入口。

### 改法

- 两个入口统一走 `requestDebtSettlement` / `confirmDebtSettlement`,
  口径统一为「结清 = 剩余本金归零」
- 结清前弹确认框,并把代价写清楚:
  「确定把"招商银行信用卡"标记为已结清吗?**剩余本金 ¥12,860.40 会清零,且不能撤回。**」
- 「恢复 / 关闭 / 暂缓」不受影响 —— 它们本来就不动本金

### 验证

浏览器实测(招商银行信用卡 ¥12,860.40):

| | 修复前(详情面板结清) | 修复后 |
| --- | --- | --- |
| 确认框 | 无 | 有,写明清零金额 |
| 状态 | 已结清 | 已结清 |
| 剩余本金 | **¥12,860.40** | **¥0.00** |
| 还款表 | 完整 12 期 | 「暂无足够的计划数据」 |

### 仍然记录在案、没有动的

- **结清之后本金真的找不回来了**:确认框现在会警告「不能撤回」,但系统没有保存
  「结清前的本金」。误点一次(即使确认过)就只能凭记忆用「编辑」重新填。
  要做就得给负债加一个「结清前本金」快照 + 一键「恢复为进行中并还原本金」——
  这是个功能,不是顺手能带上的
- 「关闭」和「暂缓」保持原样:它们只是标记状态,不动本金,也不该动
