## 表格表头补 `scope="col"` 与 `aria-sort`

先量了表单标签覆盖:13 个路由 + 两个弹层,所有可见输入框都有可访问名称,无需修。
于是转去看表格。

- 交易列表 18 个 `<th>`:排序状态原本只有视觉箭头(`日期 ↓` / `类型 ⇅`)
- 每个表头加 `scope="col"`;当前排序列加 `aria-sort`,其余 `"none"`
  (**必须挂在表头单元格上,挂在 button 上不生效**)
- 箭头 span 加 `aria-hidden`;汇率表、预算向导明细表、打印摘要表同样补 `scope`
- 实测:点「金额」→ 金额 `descending`、日期回落 `none`;再点 → `ascending`
