## 修:6 处无障碍问题,其中两处是**功能坏了**,不只是"体验不好"

这一轮不再修账务逻辑,而是对照 W3C WCAG 2.2 逐条实测"这个界面到底能不能用"。
一共修了 6 项,但真正值得先说清楚的是其中两条 —— 它们不是"少个标签",
而是**功能对特定用户完全不可用**。

### 最要紧的两条

| 问题 | 后果 |
| --- | --- |
| 交易详情**只能用鼠标点开**(行是 `tabIndex={-1}`,行内 0 个按钮) | 纯键盘用户**看不了任何一笔交易的详情**,连按 40 次 Tab 都碰不到一行 |
| 交易页分栏分隔条**拖不动** | 分隔条明明显示着、还是 `col-resize` 光标,拖了却没反应(实测 `mainW` 720 拖完还是 720) |

第二条是修第一条时顺带发现的**既存 bug**,不是这轮引入的。根因是判"要不要上下堆叠"
用了两把尺子:CSS 按**视口**宽度切(`@media max-width:1100px` 改单列并隐藏分隔条),
JS 按**容器**宽度算(`total <= 1100`)。视口 1440 时容器正好 1084 ——
CSS 认为"没堆叠、照常显示",JS 认为"已堆叠、把调整逻辑关掉"。

### 全部 6 项

| # | 问题 | 条款 |
| --- | --- | --- |
| 1 | 全站没有跳转链接,键盘用户每换一页都要 Tab 穿过整条侧边导航 | 2.4.1 (A) |
| 2 | 所有路由共用同一个 `document.title`,标签页/书签分不出页面 | 2.4.2 (A) |
| 3 | 12 条路由 `h1` 数量为 0;404 页还在 `<main>` 里又套了一个 `<main>` | 2.4.6 (AA) / 1.3.1 |
| 4 | 切页后焦点掉到 `<body>`,读屏用户听不到"已换页" | 2.4.3 |
| 5 | 交易列表整行详情、侧栏宽度只能拖,键盘改不了 | 2.5.7 (AA) |
| 6 | 分页写「首页」而可访问名是「第一页」,语音控制用户喊屏幕上的字匹配不到 | 2.5.3 (A) |

### 三个值得记下来的坑

**一、"条件性 h1"。** 第 3 条的根因很典型:侧栏品牌名写成了 `<h1>`,但只在侧栏折叠时渲染;
而真正的页面标题(`currentWorkspaceTitle`)渲染成了 `<div>`。于是侧栏展开时全站 0 个 h1,
折叠时又变成 2 个。现在约定:**顶栏标题就是页面唯一的 `<h1>`**,正文区块从 h2 起。
改这个不能只改标签 —— 这些页面的样式是 `.xxx-header h1` 这种"类名 + 标签"复合选择器,
只换标签会直接丢样式,必须同步补选择器(实测 8 个页面的字号全部保持原值)。

**二、`StrictMode` 会骗过"首渲染标志位"。** 第 4 条第一版用 `useRef(true)` 标记首渲染来避免
抢焦点,结果**初次加载焦点就被抢走了**。原因是开发环境下 StrictMode 把 effect 连跑两次,
标志位只挡得住第一次。改成"比较上一次路径"的幂等写法才对。

**三、误报比漏报更容易骗自己。** 2.5.3 的扫描一上来报了 62 条,剔除图标字形(▴ 🐞 ⋯)
和 emoji(🍜 餐饮)之后剩 25 条,再复核**全部是误报** —— 名字里其实都含有真实文字。
真正要修的只有分页 4 个按钮和日期控件。这类检查不做二次核对,很容易把界面改坏。

### 顺带修好的

- 侧栏宽度按 ARIA Window Splitter 补了键盘入口:←/→ 调 16px(Shift 48px),Home/End 到两端,
  `aria-valuenow` 让读屏念得出「当前 260,范围 220 到 420」。
- 分栏分隔条原来有 `role="separator"` 和 `aria-label`,却没有 `tabIndex`、没有键盘处理、
  没有 `aria-value*` —— 等于"告诉读屏这是分隔条,却动不了"。
- `560`/`320` 这两个魔数原来散在三处,提成了具名常量。

### 验证

- 前端 **175 文件 / 1285 测试**全过,服务端 65/65,15 个静态门全绿。
- **21 条路由实测全部通过**:每条 1 个 `h1`、无跳级、恰好 1 个 `main` 且不嵌套、
  有跳转链接、`#main-content` 存在、无重复 id、文档标题唯一。
- 关键修复做了**破坏性验证**:把行的 `tabIndex` 改回 `-1`,新测试立刻失败
  (`expected '-1' to be '0'`),恢复后全过 —— 确认测试真能挡住回归。
- 截图核对 `/help`、`/smart-budget`、`/transactions`:布局与字号无变化。

### 这轮的取舍

还有 4 处拖拽只有拖拽入口(详情抽屉拉伸、表格列宽/列序、汇率分栏、AI 浮窗)。
列宽这类精确值很难真的用"一次点击"替代,需要先想清楚方案 ——
**没有为了消掉一条检查项,塞进没想清楚的按钮。**
