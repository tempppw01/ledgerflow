# LedgerFlow v0.6.3

发布日期：2026-08-02

LedgerFlow v0.6.3 聚焦数据库基础、账号安全和投资理财工作台，补齐了从首次初始化、登录设备管理到投资资讯交叉核验和备份恢复的完整链路。

## 数据库与多账号

- 首次启动支持选择 SQLite 或 MySQL，并在初始化前检查当前环境和连接配置。
- 初始化完成后自动进入应用，避免数据库设置页停留或在日常记账时重复闪现初始化检查。
- 建立 SQL 数据库结构和关系型数据仓库，账号、业务数据和备份恢复按用户隔离。
- 增加注册、登录、资料修改、密码更新、会话撤销和当前登录设备管理。
- 账号菜单统一提供账号设置和退出登录入口。

## 投资工作台

- 持仓、自选基金和基金流水支持更紧凑的监控卡片布局。
- 持仓份额可直接点击编辑，回车后写入持久化数据。
- 增加多指数行情、市场快讯、热门题材和行业板块信息展示。
- 优化投资 AI 聊天的侧栏展开、辅助过程折叠、资讯引用、模型选择和滚动体验。
- 增加投资分析图表和更易读的基金资料展示，减少重复和过大的信息卡片。

## 联网资讯与 AI

- 投资资讯同时支持同花顺和雪球，作为互相备份的数据来源。
- Tavily 联网检索可用于投资理财 AI 的参考信息，并展示联网状态、相关资讯和引用来源。
- 投资回答增加对政策、社会新闻和市场资讯的参考入口，降低单一来源失败导致的空结果。
- 优化 AI 回复的结构化内容渲染，避免将内部 JSON 直接展示给用户。

## 备份、部署与文档

- JSON、WebDAV、阿里云 OSS、S3 兼容存储和数据库快照支持按范围备份。
- JSON、WebDAV 和对象存储恢复统一写入当前 SQL 数据库，并在恢复前进行校验。
- 本地 JSON 备份导入时显示紧凑进度条、总条数和剩余待完成条数。
- 更新 Docker Compose 部署模板、环境变量注释、数据库初始化说明和项目截图。
- README 同步更新当前版本、部署方式、投资理财能力和数据持久化说明。

## 升级提醒

- 升级前请保留 JSON、WebDAV、OSS 或数据库快照备份。
- 使用 MySQL 时，请确认 `DATABASE_PROVIDER=mysql`、`MYSQL_URL` 及数据库服务已正确配置。
- 使用 Docker Compose 时，请继续将 `/app/data` 挂载到持久化目录。
