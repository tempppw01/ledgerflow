# LedgerFlow 计划索引

> 计划目录已收敛为“单一主线计划 + 完成汇总 + 历史归档”。

## 当前主入口

### 当前主线计划
- 文件：`plans/当前主线计划.md`
- 状态：进行中
- 说明：统一维护当前未完成事项、页面改动规范流程、版本发布规范流程。

### 已完成汇总
- 文件：`plans/已完成汇总.md`
- 状态：持续追加
- 说明：记录已经完成并归档的事项，用于追溯与发布整理。

## 历史归档

- 目录：`plans/archive/`
- 说明：仅保留历史计划与兼容入口文件，不再作为当前主线入口。

## 当前规则

1. `plans/` 根目录只保留主入口、完成汇总和版本索引
2. 当前未完成事项只维护在 `plans/当前主线计划.md`
3. 已完成事项统一写入 `plans/已完成汇总.md`
4. 历史已完成或被新主线接管的计划文件统一移入 `plans/archive/`
