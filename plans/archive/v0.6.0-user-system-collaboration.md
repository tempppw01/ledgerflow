# LedgerFlow v0.6.0 用户系统与协作能力计划

> 创建日期：2026-03-07
> 状态：历史储备，已由 `plans/当前主线计划.md` 的“数据库优化与账号服务主线”接管账号基础能力；本文仅保留协作与共享方向，暂不作为当前执行入口。

## 1. 计划定位

本文件是历史远期储备，记录账号服务切入主线之前对用户系统与协作能力的初步设想。

当前账号注册、登录、会话、用户隔离、旧数据迁移和数据库基础能力，统一以 `plans/当前主线计划.md` 的 2.4 节为准，避免两个文件同时维护同一套认证方案。

---

## 2. 后续可扩展方向

### 2.1 多人共享账本 / 家庭账本

- 邀请成员
- 权限分级（查看 / 编辑 / 管理）
- 操作留痕

### 2.2 分享升级为协作

- 分享账单从“只读导出”升级到“受控共享”
- 讨论、备注、审阅状态等扩展能力

---

## 3. 执行原则

1. 账号基础能力以当前主线计划为唯一执行入口。
2. 协作能力等账号隔离、权限和审计基础稳定后再评估优先级。
3. 协作能力切入主线前，补充独立的权限模型和架构设计文档。
